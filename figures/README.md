# figures/

Publication/report figures generated **from `results/metrics/`** (and seeded
qualitative samples from `results/raw_outputs/`).

- Figures are regenerated by scripts, not hand-edited, so they stay reproducible.
- Qualitative galleries use a **seeded, documented sampling** procedure — no
  cherry-picking (CLAUDE.md Rule #10). Each example cites its `sample_id`.
- Expected: cross-model bars (RQ1), specialization groups (RQ2), prompt-tier
  curves (RQ3), scale plots (RQ4), accuracy/latency/cost Pareto (RQ5), error
  taxonomy breakdowns.
